# 🎮 Tic Tac Toe Game

---

## 📌 Project Overview

Tic Tac Toe is a classic two-player strategy game built using Python. Players take turns marking spaces in a 3×3 grid with X or O. The first player to align three symbols horizontally, vertically, or diagonally wins the game.

## 🎲 How to Play

1. The game starts with Player X.
2. Players take turns placing their symbol (X or O) on the grid.
3. The first player to get three symbols in a row wins.
4. If all cells are filled and no player wins, the game ends in a draw.
5. Click **Restart** to start a new game.

---

## 📊 Game Rules

* Three matching symbols horizontally = Win
* Three matching symbols vertically = Win
* Three matching symbols diagonally = Win
* No empty cells and no winner = Draw
